Building the Future of Linux Graphics

The Xylum Foundation is dedicated to creating safe, modern, and open-source infrastructure for the Linux ecosystem, starting with a complete rewrite of the X11 display server.

Releases About us

Our Mission

For decades, the Linux desktop has relied on legacy codebases written in unsafe languages. We believe it's time for a change. The Xylum Foundation exists to build the next generation of display servers, window managers, and core desktop infrastructure using Rust, ensuring memory safety without sacrificing performance.
