Xay11 Documentation

Technical documentation for the Wayland-on-X11 compatibility layer.

Work in Progress

Xay11 is currently in the planning and research phase. The APIs and architecture described here are subject to change.

Concept

Xay11 aims to provide a bridge that allows Wayland clients to connect to an X11 display server. It will act similarly to how Xwayland works, but in reverse.

Instead of an X11 server running inside a Wayland compositor, a Wayland compositor's core logic will be adapted to act as a client of Xylum.

Built on YComp

The rendering pipeline, surface management, and protocol parsing for Xay11 will be derived from YComp, the experimental Wayland compositor developed by the foundation.

This code reuse ensures that we don't reinvent the wheel and can leverage years of testing from the Y.Org project.

Roadmap

  • [ ] Port YComp's Wayland protocol handling to the Xay11 architecture.
  • [ ] Implement the X11-side IPC and window management.
  • [ ] Test with native Wayland applications (e.g., weston-terminal, GTK4 apps).
