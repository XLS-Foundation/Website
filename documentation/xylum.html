Xylum Documentation

Everything you need to build, run, and understand the Xylum X11 display server.

1. Prerequisites

Before building Xylum, ensure you have:

  • Rust (Edition 2024) installed via rustup.
  • A Linux environment.
  • xauth installed (for generating security cookies).

2. Building

Clone the repository and build the workspace in release mode:

git clone https://github.com/Xylum-Foundation/Xylum.git
cd Xylum
cargo build --release

3. Running Xylum

Xylum uses MIT-MAGIC-COOKIE-1 for authentication. You need to generate a cookie for the display you plan to use (e.g., :2):

xauth add :2 . $(mcookie)

Then, start the server:

cargo run --release -p xylum-server

By default, Xylum listens on /tmp/.X11-unix/X2 (Display :2).

4. Running Applications

In a separate terminal, launch any classic X11 application by pointing it to the Xylum display:

DISPLAY=:2 xeyes
DISPLAY=:2 xterm
DISPLAY=:2 xcalc

Architecture Overview

Xylum is designed with modularity in mind:

  • xylum-protocol: Handles the low-level X11 wire protocol (encoding/decoding requests and replies).
  • xylum-auth: Manages MIT-MAGIC-COOKIE-1 authentication.
  • xylum-server: The core server loop, state management, and dispatcher.

For a deeper dive into the code structure, check out the GitHub repository.
