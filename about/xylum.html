Xylum

The modern X11 display server.

Why a new X11 server?

X11 is a robust and battle-tested architecture. It allows for remote display, network transparency, and a separation between the server and the client. However, the reference implementation (X.Org) is written in C and carries decades of legacy code. Xylum was created to maintain the X11 philosophy while completely rewriting the internals in Rust.

Architecture

Xylum is built from the ground up. It parses the X11 wire protocol natively, manages its own resource database, and handles window hierarchy. By leveraging Rust's ownership model, Xylum eliminates use-after-free, double-free, and buffer overflow vulnerabilities that are common in display servers.

Rendering

Currently, Xylum uses software rendering via softbuffer to present the framebuffer. Our roadmap includes a transition to Vulkan, which will allow hardware-accelerated compositing and zero-copy buffer sharing.
