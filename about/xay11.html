Xay11

Wayland application support for X11 Servers.

Inverting the Compatibility Layer

For years, the Linux desktop has used Xwayland to run legacy X11 applications on modern Wayland compositors. Xay11 flips this concept: it provides a compatibility layer that allows modern Wayland applications to run on top of an X11 server.

Built on Proven Code

Xay11 is not starting from scratch. It leverages the core rendering and protocol logic developed for YComp (formerly Y.Org), our experimental Wayland compositor. By reusing YComp's Rust codebase, Xay11 will bridge the gap between the two display protocols.
